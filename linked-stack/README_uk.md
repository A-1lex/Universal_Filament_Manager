# Доопрацювання Spoolman + HaspelSync

Подальша робота переноситься на вже встановлену зв'язку з
`D:\Filament_Manager`. Окрема копія HaspelSync розміщена в `haspelsync/`,
гілка `fix/safe-consumption-booking`. Базовий коміт: `253afa0`.
Український переклад скопійовано з установленого проєкту.

Перший пакет змін `1.3.4-local.1`:

- блокує списання за неоднозначного або неповного призначення котушок;
- вимикає повтор HTTP-запиту, який повторно збільшував би витрачену масу;
- зберігає журнал спроб та підтверджені результати списань;
- блокує повтор невизначеної спроби після обриву зв'язку чи завершення процесу;
- додає захищене API перегляду журналу;
- зберігає наявний український інтерфейс і використовує встановлені залежності
  в окремому Docker-образі.

Технічні межі, перевірки та збірка:
[local-safe-booking.md](haspelsync/docs/local-safe-booking.md).
Spoolman, його база, робочі контейнери й налаштування принтера під час підготовки
цього пакета не змінюються. Пакет потребує окремого застосування до розгортання.

Наступні змістовні доповнення: історія завершених друків у вебінтерфейсі,
перегляд і підтвердження невизначених списань, зважування та собівартість.
Зміни основної бази Spoolman варто робити лише там, де її API недостатньо.
