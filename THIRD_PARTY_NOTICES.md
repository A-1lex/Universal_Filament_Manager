This file does not select a license for UFM's own code.

## Native Studio distribution

- The native preview uses PySide6-Essentials and shiboken6 (Qt for Python).
  Their installed metadata identifies LGPL/GPL alternatives, while this local
  collection found `LicenseRef-Qt-Commercial` notice files. The exact included
  Qt modules and applicable license obligations for a release must be resolved.
  `uv.lock` pins PySide6/Shiboken Windows wheels hosted on PyPI, but neither
  metadata alternatives nor the collected file alone proves which terms apply
  to the final bundled modules. See https://doc.qt.io/qtforpython-6/licenses.html
  and https://doc.qt.io/qtforpython-6/commercial/index.html.
- The local Windows bundle is built with PyInstaller. Its upstream license and
  bootloader exception are collected for reference; generated bundles must comply
  with dependency licenses. See https://pyinstaller.org/en/stable/license.html.
- `scripts/collect_studio_notices.py` seeds its runtime inventory from the
  source `pyproject.toml` base dependencies and `desktop` extra, then follows
  installed distribution metadata for transitive requirements and copies
  available license/notice files into the bundle's `third-party` directory.
  `runtime-dependencies.json` records each package's copied notice filenames
  alongside its metadata expression so missing or ambiguous entries are
  reviewable. Metadata expressions and file counts are not a complete SBOM or
  distribution compliance approval.
- The standalone Windows folder build includes the official Node.js v24.22.1
  Windows x64 executable and its upstream `LICENSE` under `third-party/node`;
  the build script verifies the official archive and executable SHA-256 before
  bundling. Node is not included in the Python wheel.
- License selection for UFM, complete Qt license/source-offer obligations,
  Microsoft runtime notices, signing and clean-machine validation remain
  public-release gates. No Bambu Studio or HaspelSync code or logos are copied
  into the native UI. The spool icon is generated by `create_studio_icon.py`.
