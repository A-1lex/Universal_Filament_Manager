Архів містить нативний пакет і документи для перевірки. `_internal` потрібно
розповсюджувати разом із EXE. Немає вимоги встановлювати Python або Docker
для локально перевіреного EXE, але окрема чиста Windows ще не протестована.

Не перевірені на реальному обладнанні: новий Qt enrollment, фізичні команди,
наскрізний друк. Автоматичне списування ще не реалізовано. Стара система
не зупинена; імпорт — незалежна копія, не двостороння синхронізація.

Під час перевірок знайдено та виправлено PATH-конфлікт сторонньої ICU DLL
у PyInstaller й порядок знищення Qt widgets. Попередні збірки після перевірки
видалені як відтворювані артефакти. Реальні дані та копії не видалялися.

Наступний етап — W13, описаний в `AUTOMATIC_ACCOUNTING_UK.md`.
Стан для відновлення — `DEVELOPMENT_HANDOFF.md`. Наявний graphify-граф
старіший за нові Studio-файли: при наступній роботі звіряти його з source;
інкрементальне оновлення можливе окремо, повна перебудова зараз не потрібна.
