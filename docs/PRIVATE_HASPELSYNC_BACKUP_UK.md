# Захищена копія приватних даних HaspelSync

Перевірено 2026-10-27. Крок E01.03 завершений для наявних локальних сховищ.

## Що збережено

Власний код уже збережений у прийнятому [baseline](INTEGRATION_BASELINE_UK.md).
Додатково `scripts/backup_haspelsync_private.ps1` архівує наявні `printers/`
та `logs/` старої системи й власного checkout, їх `.env`, загальний `.env`
Filament_Manager за наявності, а також compose. Дані не змінюються.

Прийнятий зашифрований знімок:
`.runtime/private-haspelsync/20261027T0428176609351Z/runtime.zip.dpapi`.
Знеособлений результат перевірки — `verification.json` поруч.
Це приватні файли, їх не можна додавати до публічного дистрибутива.

Збережені 9 файлів: налаштування принтерів, mappings, printstate, settings,
чотири історичні лог-файли та compose. Назви, які містять серійні номери,
і повний файловий manifest знаходяться лише всередині шифрованого архіву.
На перевірених шляхах `presets.json`, `bookings.json`, `accounting.json`,
`apikeys.json` відсутні; власний checkout не має `printers/` та `logs/`.
Відсутні журнали не створювали й не підміняли порожніми. Історичний облік,
який є лише в логах або SQLite, збережено відповідними копіями.

## Шифрування та перевірка

ZIP формується в пам’яті й захищається Windows DPAPI CurrentUser.
Незашифрований архів, конфігурації, LAN-коди й токени на диск не записуються.
Перед шифруванням скрипт повторно перевіряє SHA256 кожного вихідного файла
та відхиляє capture, якщо виявлено зміну його вмісту. Це перевірка стабільності
прочитаних файлів, а не транзакційна блокада працюючого HaspelSync.

Після запису скрипт повторно читає зашифрований файл, розшифровує його
в пам’ять, відкриває ZIP, відновлює кожен запис у пам’ять і звіряє його
розмір та SHA256 із внутрішнім manifest. Окрема повторна перевірка першого
знімка також успішна; змінений на один байт DPAPI-файл відхилено.
Синтаксис PowerShell перевірений. Модулі програми й встановлений EXE незмінні;
повний suite цією перевіркою не замінюється.

Потрібен PowerShell 7.2+ та Windows. Для нового знімка:

```powershell
./scripts/backup_haspelsync_private.ps1
```

Для перевірки прийнятого знімка без запису відкритих секретів:

```powershell
./scripts/backup_haspelsync_private.ps1 -VerifyBundle '.runtime/private-haspelsync/20261027T0428176609351Z/runtime.zip.dpapi'
```

## Межі відновлення

Це локальна аварійна копія: відновлення потребує початкового профілю Windows
і його ключів DPAPI. Копіювання одного файла на інший ПК або перевстановлення
Windows не гарантує розшифрування. Парольний переносний експорт ще не реалізований.
Наявна команда перевіряє відновлення в пам’яті, не встановлює конфігурації
у робочий runtime й не перемикає власника списування. Під час міграції треба
читати цю копію через DPAPI тим самим обліковим записом та переносити секрети
безпосередньо в захищене сховище програми. Реальні конфігурації залишені на місці.

Наступний етап — E02: інвентаризація екранів, кнопок та автоматичних сценаріїв.
E01.01 залишається частковим: запущений legacy runtime наразі не підтверджений.
